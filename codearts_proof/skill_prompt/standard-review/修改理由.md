# standard-review · Prompt 迭代说明（v1 → final）

## v1 的问题
- 只提"格式、命名"，遗漏注释、冗余、异常提示等规范面；
- 无严重度区分，所有问题平铺，汇总时无法排序；
- 无固定输出格式。

## final 版的修改点与理由
1. **明确规范视角**：编码规范、可读性、命名、注释、格式、工程编码约定；
2. **枚举评估维度**：命名规范、注释完整性、代码格式、函数长度、魔法数字、冗余代码、异常提示文本、导入顺序；
3. **要求写"影响"字段**：说明不规范点对可读性/维护性的实际影响；
4. **固定输出结构**：【规范评审结论】规范等级（整洁/基本合规/较多问题/混乱）+【规范问题清单】（位置/问题/影响/修改建议）。

## 迭代效果
对测试样例按 P0–P3 输出分级规范意见（残缺 SQL 必须修、注解与 docstring 建议修、引号风格统一格式化时处理），见 `run_log/skill_standard_test.md`。
